# 组件无障碍验收标准（模板）

> 每个新组件合入前按此清单自测。组件级 DoD（Definition of Done）的一部分。

- **组件名**：
- **类型**：按钮 / 输入 / 弹窗 / 菜单 / 标签页 / 列表 / 其它
- **负责人**：

## 语义与角色

- [ ] 优先使用原生元素（`<button>`/`<a>`/`<input>`…），未滥用 `role`
- [ ] 如用 ARIA，`aria_lint.py` 0 error（角色合法、必需子角色齐全、无冗余 role）
- [ ] 装饰性节点已 `aria-hidden`，且其内无可聚焦元素

## 键盘与焦点

- [ ] 所有交互可用键盘完成（Tab / Enter / 方向键 / Esc）
- [ ] 无键盘陷阱；模态可 Esc 关闭并归还焦点
- [ ] 焦点可见（`:focus-visible` 有清晰指示）
- [ ] 组合组件用 roving tabindex，方向键可导航

## 名称与状态

- [ ] 每个控件有可访问名称（可见文本 / `aria-label` / 关联 `<label>`）
- [ ] 状态（展开/选中/禁用/必填/错误）通过标准 aria-* 暴露
- [ ] 名称与可见文案一致，无冲突

## 视觉与对比

- [ ] 文本对比度 ≥ 4.5:1（大字 ≥ 3:1）—— `contrast_check.py`
- [ ] 组件边界/状态图标对比度 ≥ 3:1
- [ ] 不只靠颜色传达状态（有文字/图标辅助）

## 动态内容

- [ ] 加载/错误/成功等提示通过 `role="alert"` / `aria-live` 播报
- [ ] 路由/显隐切换后焦点移动到正确位置

## 静态自检

```bash
python3 scripts/a11y_audit.py <组件渲染的 html> --strict
python3 scripts/aria_lint.py <组件渲染的 html> --strict
```
